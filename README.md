# Trailing Whitespace Trimmer

Highlights extraneous trailing whitespace and supports one-click trimming

## Details
- **Identifier**: `matn.ext.trailing`
- **Version**: `1.0.0`
- **Category**: `editor`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Trailing Whitespace Trimmer**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-trailing
```
